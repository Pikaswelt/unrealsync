# Contributing to UnrealSync

Thank you for your interest in contributing to UnrealSync! We welcome all contributions that help indie game developers collaborate effortlessly on Unreal Engine projects.

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. **Install Dependencies & Test**:
   ```bash
   npm install
   npm run dev
   npm run build
   ```
4. **Commit Your Changes**:
   ```bash
   git commit -m "feat: add support for custom git attributes"
   ```
5. **Push and Submit a Pull Request**.

## Guidelines
- Follow clean modern JavaScript / React conventions.
- Keep the UI responsive, dark-themed, and game-dev oriented.
- Test your changes against real Unreal Engine 5 project directories.
